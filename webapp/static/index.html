Configure source

› How to configure
  1. Open the doc in Google Docs, one IP or CIDR block per line.
  2. File → Share → Publish to web → Publish, then copy the link it gives you.
  3. Paste that link below. It'll look like https://docs.google.com/document/d/e/…/pub -- that's the right kind of link (this dashboard reads the page's text content either way, so a plain-text URL from anywhere else works too, not just Google Docs).
  4. In that same Publish to web dialog, make sure "Automatically republish when changes are made" is checked -- otherwise edits to the doc won't show up here until you come back and republish by hand. Even with it checked, Google can take a few minutes to actually update the published page after each edit.
